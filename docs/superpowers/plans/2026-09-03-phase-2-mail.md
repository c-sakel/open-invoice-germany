# Phase 2 — Mailversand, Textvorlagen, Platzhalter, E-Mail-Historie: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Belege (Angebot, Auftragsbestätigung, Rechnung, Storno/Gutschrift, Mahnung) per SMTP aus der Anwendung versenden — mit im UI gepflegten Mailserver-Daten, editierbaren Standardtexten mit Platzhaltern, Versandfenster mit CC/BCC/Anhängen/Vorschau und vollständiger, GoBD-protokollierter Versandhistorie.

**Architecture:** Reine Domain-Module (`src/lib/template`, `src/lib/crypto`, `src/domain/email`) ohne Next-Abhängigkeit; ein `MailProvider`-Interface mit SMTP-Implementierung (nodemailer) und einer In-Memory-Implementierung für Tests; Versand über eine API-Route (multipart, Zusatzanhänge), Einstellungen/Vorlagen über Server Actions; jeder Versand schreibt `EmailLog` + `ChangeLog`.

**Tech Stack:** Next.js 16 App Router, TypeScript strict, Prisma 6.19.3 (SQLite + Postgres, zwei Schemas, zwei Migrationsverzeichnisse), Zod 4, vitest, nodemailer, node:crypto (AES-256-GCM, HKDF).

**Spec:** `docs/superpowers/specs/2026-09-03-phase-2-mail-design.md` (Branch `specs`; Kopie im Scratchpad unter `plan/2026-09-03-phase-2-mail-design.md`).

## Global Constraints

- Keine Prisma-Enums (String + Zod); kein Json-Typ (serialisierte Strings); Geld Integer-Cent; Zod an jeder Boundary (Route, Action).
- Beide Schemas `prisma/schema.prisma` und `prisma/schema.postgres.prisma` byte-gleich bis auf die Provider-Zeile; jede Migration in beiden Dialekten; Migrationen idempotent gegen leere und befüllte DB. Postgres-Migration über `npm run db:migrate:pg -- --name <name>` (Wrapper `scripts/migrate-postgres.sh`, braucht laufenden Postgres-Container — siehe `scripts/test-postgres-migrations.sh`) oder von Hand aus der SQLite-Migration abgeleitet und per `--config prisma.postgres.config.ts` verifiziert.
- GoBD: festgeschriebene Rechnungen unveränderbar; `ChangeLog` per `appendChangeLog(tx, …)` innerhalb derselben Transaktion; Guard in `src/lib/db.ts` bleibt.
- Phase-0-Snapshot-Regel: Werte für festgeschriebene Belege aus `sellerSnapshotJson`/`buyerSnapshotJson` (`parseSellerSnapshot`/`parseBuyerSnapshot` aus `@/domain/snapshot`), nicht aus dem Stamm.

- Interne Notizen (`internalNotes`) erscheinen nie in Mails.
- Deutsche Kommentare; Commit-Messages ohne Umlaute; jeder Commit `git commit -s`.

`src/lib/crypto/secrets.ts`:

```ts
/**
 * Verschluesselung von Geheimnissen (SMTP-Passwort) in der Datenbank.
 * Schluessel: HKDF-SHA256 aus AUTH_SECRET, Info "oig-mail-settings-v1".
 * Format: v1:<iv b64>:<tag b64>:<ciphertext b64>
 * Achtung: Wechsel von AUTH_SECRET macht gespeicherte Geheimnisse unlesbar (dokumentiert).
 */
import { createCipheriv, createDecipheriv, hkdfSync, randomBytes } from "node:crypto";

export class SecretsUnavailableError extends Error {
  constructor() {
    super("AUTH_SECRET ist nicht gesetzt — Zugangsdaten koennen nicht verschluesselt gespeichert werden.");
    this.name = "SecretsUnavailableError";
  }
}

const INFO = "oig-mail-settings-v1";

function key(): Buffer {
  const secret = process.env.AUTH_SECRET;
  if (!secret || secret.length < 16) throw new SecretsUnavailableError();
  return Buffer.from(hkdfSync("sha256", secret, "", INFO, 32));
}

export function encryptSecret(plain: string): string {
  const k = key();
  const iv = randomBytes(12);
  const cipher = createCipheriv("aes-256-gcm", k, iv);
  const ct = Buffer.concat([cipher.update(plain, "utf8"), cipher.final()]);
  const tag = cipher.getAuthTag();
  return ["v1", iv.toString("base64"), tag.toString("base64"), ct.toString("base64")].join(":");
}

export function decryptSecret(enc: string): string {
  const [v, ivB, tagB, ctB] = enc.split(":");
  if (v !== "v1" || !ivB || !tagB || !ctB) throw new Error("Unbekanntes Geheimnisformat");
  const decipher = createDecipheriv("aes-256-gcm", key(), Buffer.from(ivB, "base64"));
  decipher.setAuthTag(Buffer.from(tagB, "base64"));
  return Buffer.concat([decipher.update(Buffer.from(ctB, "base64")), decipher.final()]).toString("utf8");
}
```

```ts
/** Deutsche Formatierung fuer Platzhalter (Datum dd.MM.yyyy, Geld 1.234,56 €). */
export function formatDateDe(d: Date | null | undefined): string {
  if (!d) return "";
  return new Intl.DateTimeFormat("de-DE", { day: "2-digit", month: "2-digit", year: "numeric", timeZone: "Europe/Berlin" }).format(d);
}

export function formatMoneyDe(cents: number | null | undefined, currency = "EUR"): string {
  if (cents === null || cents === undefined) return "";
  const sign = cents < 0 ? "-" : "";
  const abs = Math.abs(cents);
  const euros = Math.floor(abs / 100).toLocaleString("de-DE");
  const rest = String(abs % 100).padStart(2, "0");
  const symbol = currency === "EUR" ? "€" : currency;
  return `${sign}${euros},${rest} ${symbol}`;
}
```

`src/lib/template/render.ts`:

```ts
/**
 * Platzhalter-Engine: {{pfad.zu.wert}}. Fehlende oder nicht-skalare Werte ergeben einen
 * leeren String und eine Warnung — nie eine Exception (Lastenheft 18).
 */
export type TemplateContext = Record<string, unknown>;

const PATTERN = /\{\{\s*([A-Za-z0-9_.-]+)\s*\}\}/g;

function resolve(ctx: TemplateContext, path: string): unknown {
  let cur: unknown = ctx;
  for (const part of path.split(".")) {
    if (cur === null || typeof cur !== "object" || !(part in (cur as Record<string, unknown>))) return undefined;
    cur = (cur as Record<string, unknown>)[part];
  }
  return cur;
}

export function renderTemplate(text: string, ctx: TemplateContext): { text: string; warnings: string[] } {
  const warnings: string[] = [];
  const out = text.replace(PATTERN, (_m, path: string) => {
    const v = resolve(ctx, path);
    if (typeof v === "string") return v;
    if (typeof v === "number" || typeof v === "boolean") return String(v);
    warnings.push(`Unbekannter Platzhalter {{${path}}}`);
    return "";
  });
  return { text: out, warnings };
}

/** Alle Platzhalterpfade eines Textes (fuer Vorschau/Editor). */
export function listPlaceholders(text: string): string[] {
  return Array.from(text.matchAll(PATTERN), (m) => m[1]!);
}
```

```ts
/** Standardanhaenge je Belegtyp (Spec, Abschnitt 2). */
export async function buildStandardAttachments(orgId: string, docType: EmailDocType, docId: string): Promise<Attachment[]> {

    const loaded = await loadEInvoiceData(docId);
    if (!loaded || loaded.invoice.orgId !== orgId) return [];
    const { invoice, data } = loaded;
    const base = safe(invoice.number ?? "Entwurf");
    const finalized = invoice.status === "FINALIZED"; // Implementer: tatsaechliches Statusfeld pruefen (finalize.ts)
    if (!finalized) {
      return [{ filename: `${base}-ENTWURF.pdf`, contentType: "application/pdf", content: await renderInvoicePdf(data) }];
    }
    const out: Attachment[] = [{ filename: `${base}.pdf`, contentType: "application/pdf", content: await renderZugferdPdf(data) }];
    if (invoice.customer.leitwegId) {
      out.push({ filename: `${base}-xrechnung.xml`, contentType: "application/xml", content: Buffer.from(buildXRechnungUBL(data), "utf8") });
    }
    return out;
  }
  if (docType === "DUNNING") {
    const d = await dbInternal.dunning.findFirst({ where: { id: docId, invoice: { orgId } }, include: { invoice: { include: { org: true, customer: true, payments: true } } } });
    if (!d) return [];
    const out: Attachment[] = [{ filename: `${safe(d.number ?? "Mahnung")}.pdf`, contentType: "application/pdf", content: await renderDunningPdf(buildDunningPdfData(d, d.invoice)) }];
    const inv = await loadEInvoiceData(d.invoiceId);
    if (inv) out.push({ filename: `${safe(inv.invoice.number ?? "Rechnung")}.pdf`, contentType: "application/pdf", content: await renderInvoicePdf(inv.data) });
    return out;
  }
  if (docType === "DELIVERY_NOTE") return []; // PDF kommt in Phase 3

  if (!q) return [];
  return [{ filename: `${safe(q.number ?? "Dokument")}.pdf`, contentType: "application/pdf", content: await renderInvoicePdf(buildDocEInvoiceData(q)) }];
```

```ts
import nodemailer from "nodemailer";
import type { DecryptedMailSettings } from "@/domain/email/settings";
import { MailSendError, type MailProvider } from "./provider";

/** SMTP-Provider (nodemailer). Fehlertexte werden von Zugangsdaten bereinigt. */
export function createSmtpProvider(s: DecryptedMailSettings): MailProvider {
  const transport = nodemailer.createTransport({
    host: s.host, port: s.port,
    secure: s.security === "TLS",
    requireTLS: s.security === "STARTTLS",
    ignoreTLS: s.security === "NONE",
    auth: s.username ? { user: s.username, pass: s.password ?? "" } : undefined,
    connectionTimeout: 20_000, greetingTimeout: 20_000, socketTimeout: 30_000,
  });
  return {
    async send(mail) {
      try {
        const info = await transport.sendMail({
          from: { name: mail.from.name, address: mail.from.address },
          to: mail.to, cc: mail.cc, bcc: mail.bcc, replyTo: mail.replyTo,
          subject: mail.subject, text: mail.text,
          attachments: mail.attachments.map((a) => ({ filename: a.filename, content: a.content, contentType: a.contentType })),
        });
        return { providerId: info.messageId ?? null };
      } catch (e) {
        const raw = e instanceof Error ? e.message : String(e);
        const cleaned = raw.replaceAll(s.password ?? " ", "***").slice(0, 500);
        throw new MailSendError(cleaned);
      }
    },
  };
}
```

```ts
export async function sendDocumentEmail(orgId: string, actor: string, input: SendEmailInput, extra: Attachment[], provider?: MailProvider) {
  const settings = await loadMailSettings(orgId);
  if (!settings) throw new MailNotConfiguredError();
  const prov = provider ?? createSmtpProvider(settings);
  const std = await buildStandardAttachments(orgId, input.docType, input.docId);
  const attachments = [...std.filter((a) => input.standardAttachments.includes(a.filename)), ...extra];
  const bcc = input.copyToSelf && !input.bcc.includes(settings.fromEmail) ? [...input.bcc, settings.fromEmail] : input.bcc;
  const text = input.signature.trim() ? `${input.body}\n\n${input.signature}` : input.body;

  const log = await dbInternal.emailLog.create({ data: {
    orgId, docType: input.docType, docId: input.docId, templateId: input.templateId ?? null, resendOfId: input.resendOfId ?? null,
    fromEmail: settings.fromEmail, replyTo: settings.replyTo ?? null,
    toJson: JSON.stringify(input.to), ccJson: JSON.stringify(input.cc), bccJson: JSON.stringify(bcc),
    subject: input.subject, bodySnapshot: text,
    attachmentsJson: JSON.stringify(attachments.map((a) => ({ filename: a.filename, size: a.content.length, sha256: createHash("sha256").update(a.content).digest("hex") }))),
    status: "queued", warningsJson: "[]", sentByUserId: actor,
  }});

  let status: "sent" | "failed" = "sent"; let providerId: string | null = null; let error: string | undefined;
  try {
    ({ providerId } = await prov.send({ from: { name: settings.fromName, address: settings.fromEmail }, to: input.to, cc: input.cc, bcc, replyTo: settings.replyTo ?? undefined, subject: input.subject, text, attachments }));
  } catch (e) { status = "failed"; error = e instanceof Error ? e.message.slice(0, 500) : "Unbekannter Fehler"; }

  await dbInternal.$transaction(async (tx) => {
    await tx.emailLog.update({ where: { id: log.id }, data: { status, providerId, error: error ?? null, sentAt: status === "sent" ? new Date() : null } });
    await appendChangeLog(tx, { orgId, entity: "EMAIL", entityId: log.id, action: status === "sent" ? "SENT" : "FAILED", actor, at: new Date(),
      diff: { docType: input.docType, docId: input.docId, to: input.to, cc: input.cc, bcc, subject: input.subject, attachments: JSON.parse(log.attachmentsJson), error: error ?? null } });
  });
  return { logId: log.id, status, error };
}
```

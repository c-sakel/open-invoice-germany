# Phase 9 — MCP-Erweiterungen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MCP deckt alle Kernfunktionen ab (§55), mit denselben Zod-Schemas und Domain-Funktionen wie UI/API, vollständigen Tests je Tool und einem Doku-Drift-Check.
**Architecture:** Nur `src/mcp/server.ts` (ggf. Aufteilung in `src/mcp/tools/*.ts` je Bereich, Registrierung in server.ts), Tests, docs/MCP.md. Keine Schemaänderung.
**Spec:** docs/superpowers/specs/2026-09-04-phase-9-mcp-design.md; Ist-Stand phase-9-ist-stand.md.

## Global Constraints
- Kein Bypass: jedes Tool ruft die Domain-Funktion, die auch Route/Server Action nutzt; Input-Zod aus `src/schemas` komponiert; Fehler über `fail()` mit Domain-Text, unbekannt generisch.
- Keine Schemaänderung, keine neuen Abhängigkeiten. Base64-Dateiantworten ≤ 10 MB (sonst `fail`).
- Testjahre 2069 core, 2070 documents, 2071 payments/recurring, 2072 email/files. Bestehende Tests unverändert.
- Prüfkette im Vordergrund: typecheck, lint, test, build, validate:erechnung.

- Liberation Sans (Standard): siehe `LICENSE-OFL.txt` und `docs/ARCHITEKTUR.md`.
- IBM Plex Sans und IBM Plex Serif: `LICENSE-OFL-IBM-Plex.txt` (der Lizenztext beider Pakete ist identisch).
- Source Serif 4: `LICENSE-OFL-Source-Serif-4.txt`.
- Inter: `LICENSE-OFL-Inter.txt`.
